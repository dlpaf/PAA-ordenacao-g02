# Implementação e Comparação de Algoritmos de Ordenação

Projeto desenvolvido para a disciplina de Estrutura de Dados e Algoritmos, com o objetivo de implementar e comparar experimentalmente o desempenho dos principais algoritmos de ordenação.

## Objetivo

A análise assintótica nem sempre evidencia diferenças práticas entre algoritmos que possuem a mesma complexidade teórica. Dessa forma, este trabalho realiza uma análise experimental baseada no tempo de execução dos algoritmos em diferentes cenários.

Os algoritmos implementados foram:

- Bubble Sort
- Insertion Sort
- Merge Sort
- Heap Sort
- Quick Sort

Todos os algoritmos seguem, o mais fielmente possível, as implementações apresentadas em sala de aula e baseadas no livro do Cormen.

---

## Cenários de Teste

Os algoritmos foram executados considerando três tipos de entrada:

1. Vetor em ordem crescente
2. Vetor em ordem decrescente
3. Vetor aleatório

---

## Tamanhos dos Vetores

Os testes serão realizados com vetores dos seguintes tamanhos:

- 100
- 1.000
- 5.000
- 30.000
- 50.000
- 100.000

- 200.000
